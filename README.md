# bank-customer-data-analysis
Bank customer data cleaning and analysis using Python and Pandas
Project Overview

This project demonstrates data cleaning, data quality validation, and exploratory data analysis using a bank customer dataset. The objective is to identify data-quality issues, prepare reliable data for analysis, and generate meaningful customer insights.

Objectives

Inspect dataset structure and data types.

Identify and investigate missing values and duplicate records.

Detect invalid numerical values, including unrealistic ages and negative financial amounts.

Standardize text fields and date formats.

Validate the dataset after cleaning.

Explore customer demographics, income, loan amounts, credit scores, and account activity.

Dataset

The practice dataset contains customer information such as age, city, monthly income, loan amount, credit score, account type, join date, and active customer status.

Data Quality Issues Investigated

The initial assessment identified invalid age values, a negative monthly income, and a negative loan amount. These values are investigated before deciding how to handle them. Any cleaning decisions should be documented and validated.
